Tiles

Legend

Rectangle: click one corner, then the opposite corner — fills the whole box with the selected tile.

Area: works like Rectangle, but select a tileset's "0" tile first (e.g. mountain0, or a future water0) and it autotiles the surrounding 8 ids around a filled center, using the same [1,2,3 / 4,0,5 / 6,7,8] layout, offset from whichever "0" tile you picked. Min size 3×3.

Check "view ids" to switch the whole editor to flat numbered colors instead of the tile images.
